# Раздел 7. Переключение между днями и выключение компьютера

## ID DAY-001
|Атрибут|Значение|
|---|------------|
|Заголовок|**Переход на следующий день после решения проблемы и выключения**|
|Предусловия|День 1 решен (команда выполнена).|
|Окружение|ПК, браузер Chrome версии 120+|
|Шаги|1. Открыть меню Пуск.<br>2. Нажать «Выключение».<br>3. Дождаться анимации выключения.<br>4. На главном экране нажать «Продолжить».|
|Ожидаемый результат|1. Загружается День 2.<br>2. В ЛК отображается новая проблема (ошибка 502).<br>3. В Telegram появляются новые сообщения для Дня 2.|
|Постусловия|Активен День 2.|
|Статус|Passed|
|Фактический результат|Выполняется в соответствии с ожиданиями|

## ID DAY-003
|Атрибут|Значение|
|---|------------|
|Заголовок|**Перезагрузка компьютера через меню Пуск**|
|Предусловия|Игра активна.|
|Окружение|ПК, браузер Chrome версии 120+|
|Шаги|1. Открыть меню Пуск.<br>2. Нажать «Перезагрузка».|
|Ожидаемый результат|1. Появляется оверлей с текстом «Перезагрузка...».<br>2. Через 2 секунды оверлей исчезает.<br>3. Рабочий стол остается активным.<br>4. Если перезагрузка происходит впервые за день, Доверие +1.|
|Постусловия|Верное отображение|
|Статус|Passed|
|Фактический результат|Выполняется в соответствии с ожиданиями|
