# Раздел 1. Главный экран и управление игрой (index.html)
## ID MAIN-001 
|Атрибут|Значение|
|---|------------|
|Заголовок|**Начало новой игры с нулевым прогрессом**|
|Предусловия|Локальное хранилище браузера очищено или не содержит сохранений игры.|
|Окружение|ПК, браузер Chrome версии 120+, разрешение 1920x1080|
|Шаги|1. Открыть файл index.html в браузере.<br>2. Нажать на кнопку «Начать новую игру».|
|Ожидаемый результат|1. Отображается рабочий стол с иконками.<br>2. В правом верхнем углу панель статистики: Доверие = 70, Интеллект = 0.<br>3. В localStorage создается ключ spbGameSave.|
|Постусловия|Игра активна, текущий день = 1.|
|Статус|Passed|
|Фактический результат|Выполняется в соответствии с ожиданиями|

|Постусловия|Игра продолжается с сохраненного момента.|
|Статус|Passed|
|Фактический результат|Выполняется в соответствии с ожиданиями|
