# Раздел 3. Панель уведомлений (Notification Panel)

## ID NOTIFY-001
|Атрибут|Значение|
|---|------------|
|Заголовок|**Отображение панели с уведомлениями**|
|Предусловия|Игра активна, есть хотя бы одно непрочитанное уведомление.|
|Окружение|ПК, браузер Chrome версии 120+|
|Шаги|1. На панели задач нажать на иконку конверта «✉».|
|Ожидаемый результат|1. Открывается панель уведомлений.<br>2. В списке отображаются уведомления с временем получения.<br>3. Бейдж с цифрой исчезает.|
|Постусловия|Панель уведомлений открыта.|
|Статус|Passed|
|Фактический результат|Выполняется в соответствии с ожиданиями|

## ID NOTIFY-002
|Атрибут|Значение|
|---|------------|
|Заголовок|**Создание уведомления при событии в игре**|
|Предусловия|Игра активна.|
|Окружение|ПК, браузер Chrome версии 120+|
|Шаги|1. Выполнить действие, создающее уведомление (например, завершить день).|
|Ожидаемый результат|1. На иконке уведомлений появляется красный бейдж.<br>2. При открытии панели новое уведомление отображается в списке.|
|Постусловия|Уведомление добавлено в список.|
|Статус|Passed|
|Фактический результат|Выполняется в соответствии с ожиданиями|
